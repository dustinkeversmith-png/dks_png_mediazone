Formants & Spectral Envelope via Eigen (LPC Root Finding)To find formants, we use Linear Predictive Coding (LPC). The model expresses sample $s[n]$ as a linear combination of previous $p$ samples:$$s[n] \approx \sum_{k=1}^{p} a_k s[n-k]$$For speech at $16\text{ kHz}$, the standard LPC order is $p = 16$ (2 poles per kHz + 2 to 4 extra for glottal shaping).The Pipeline:Autocorrelation: Compute $r[k] = \sum_{n=0}^{N-1-k} x[n] x[n+k]$ for lags $k = 0 \dots p$.Levinson-Durbin: Solve the Toeplitz system $R \mathbf{a} = \mathbf{r}$ to extract LPC filter coefficients $a_1, a_2, \dots, a_p$.Companion Matrix & Eigenvalues (Root Finding): Build the companion matrix of polynomial $A(z) = 1 - \sum_{k=1}^{p} a_k z^{-k}$. The eigenvalues of this matrix are the complex roots $z_i$.Formant Frequency & Bandwidth:$$F_i = \frac{\text{atan2}(\text{Im}(z_i), \text{Re}(z_i)) \cdot f_s}{2\pi}, \quad B_i = -\frac{f_s}{\pi} \ln \vert{}z_i\vert{}$$

Quick Synthesis: Spectral Envelope vs. Power SpectrumTo extract the smooth Spectral Envelope using the LPC coefficients $a_k$:Allocate an array of length $512$ (or whatever your FFT size is).Set index $0$ to $1.0$, and indices $1 \dots 16$ to $-a_1, -a_2, \dots, -a_{16}$ (zero-padded to 512).Run this vector through FastFFT.The LPC Spectral Envelope is:$$\text{Envelope}[k] = \frac{1}{\sqrt{\vert{}A[k]\vert{}^2}}$$Passing your raw power spectrum through the FFT gives you the detailed harmonic spikes (glottal source), while the LPC envelope tracks the smooth resonant shape (the formants).
