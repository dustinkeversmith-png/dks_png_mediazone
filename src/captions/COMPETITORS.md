Kaldi (and Vosk / Alpha-Vosk):Architecture: Kaldi compiles the entire search graph ahead of time into a static WFST. Vosk packages Kaldi's online lattice decoder into lightweight C/C++ runtimes.Accuracy: ~5–12% WER on LibriSpeech clean (using TDNN-F acoustic models) or ~15–22% WER using pure triphone GMM-HMM setups.Latency & Throughput: Truly streaming (10–30 ms chunk processing), zero lookahead required, running at 20× to 50× RT on a single CPU core.Determinism: Decoding is completely deterministic given fixed beam parameters.PocketSphinx (CMU Sphinx v5):Architecture: The classic open-source reference for embedded devices. It uses 3-state left-to-right HMMs, senone decision trees, and an $N$-gram beam search decoder.Accuracy: ~18–25% WER on clean read speech (LibriSpeech/WSJ); degrades in noise.Determinism: Highly deterministic, tiny memory footprint (<30 MB), and sub-10 ms latency on CPU.Julius:Architecture: A high-performance two-pass decoder developed in Japan. Pass 1 runs frame-synchronous Viterbi beam search with a monophone/triphone HMM and 2-gram LM; Pass 2 performs backward stack decoding with a 3-gram or grammar-based network.Use Case: Excellent for command-and-control, isolated vocabularies, and low-latency continuous captioning where memory is strictly constrained.
